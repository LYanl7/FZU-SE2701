# 一箭又一箭

基于 Python + Pygame 的小游戏项目。

## 项目分层

- `src/presentation`：表现层，负责用户输入、界面渲染与动画播放。
- `src/logic`：逻辑层，负责处理用户操作、碰撞检测及胜负判定。
- `src/model`：数据模型层，负责维护箭头、网格及游戏状态。

## 开发环境

- Python 3.10+
- Pygame 2.5+
- uv 0.10+

## 启动

使用 `uv` 创建项目本地虚拟环境，依赖不会安装到全局 Python：

```bash
uv sync
uv run python main.py
```

如果希望把 uv 缓存也放在 D 盘，可以在 PowerShell 中执行：

```powershell
$env:UV_CACHE_DIR = "D:\SE-2701\task02\.uv-cache"
uv sync
uv run python main.py
```

当前版本已支持基础玩法，包括多关卡、直线与分段箭头、箭头阻挡判定、失误次数管理、胜利/失败界面，以及箭头飞出动画和碰撞反馈动画。

## 自动生成关卡

- 游戏启动后第一关就是随机生成的；项目不再加载内置关卡。
- 每关使用高密度箭头；箭头由 2～6 个全局点坐标组成，相邻点连接成真正的横纵折线。
- 四个箭头方向按中央生成区域的相对位置计算，避免宽棋盘导致方向集中在上下。
- 造型以长直线和“长—短—长”两次折弯为主，一次折弯次之，仅少量使用连续多折，避免视觉疲劳。
- 棋盘保持横向铺满窗口，箭头只生成在中间约 70% 的范围，左右两侧留空。
- 通关后点击“下一关”会继续生成密度和规模逐步提高的新关卡。
- 首页仅保留“开始游戏”，游戏中也不再显示“随机关卡”。
- 使用鼠标滚轮或棋盘正下方的 `－` / `＋` 可以缩放棋盘；缩放只作用于内部坐标与箭头，棋盘外框占比始终不变。
- 生成器会检查箭头不重叠，并在展示前求出一条完整解法，避免生成死局。
- 调试或测试时可使用固定种子复现关卡：`GameController(generation_seed=2026)`。
